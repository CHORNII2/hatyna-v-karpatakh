# CLAUDE.md — правила проєкту

## Проєкт
Демо-сайт «Хатина в Карпатах»: календар бронювання та калькулятор вартості для котеджу. Тестове завдання на вакансію Junior AI Web Developer (Semalt). Повний план — у `PLAN.md`, дизайн — у `DESIGN.md`, чеклист перевірки — у `TESTING.md`.

## Про власника
Микола — початківець у веб-розробці, базово знає HTML/CSS/JS. Код пишеш ти, він керує, перевіряє й тестує. Тому:
- Спілкуйся **українською**, простими словами, без зайвого жаргону.
- Перед великою зміною коротко опиши план і дочекайся «ок».
- Працюй малими кроками. Після кожного кроку: що зроблено, які файли змінено, **що Миколі перевірити вручну**.
- Не додавай нічого, про що не просили. Не вигадуй функцій.
- Коментарі в коді короткі, українською, лише там, де логіка неочевидна.

## Стек і обмеження
- Чистий HTML, CSS, JavaScript (ES modules). **Без фреймворків, без npm-збірки, без бекенду.**
- Зовнішні бібліотеки не підключати. Шрифти — системні або локальні файли.
- Дані — у JSON (`data/`). Збереження чернетки — `localStorage` з try/catch.
- Жодних ключів, токенів, реальних контактів та реальних персональних даних у коді. Усі дані демонстраційні.
- Мова інтерфейсу: українська. `<html lang="uk">`.

## Структура
```
/index.html         головна
/booking.html       застосунок бронювання
/css/style.css      єдиний файл стилів (змінні в :root)
/js/calendar.js     рендер календаря, вибір діапазону
/js/pricing.js      чиста функція розрахунку вартості (легко тестувати)
/js/booking.js      зв'язує UI, валідацію, форму, localStorage
/data/bookings.json зайняті дати
/data/pricing.json  сезони, тарифи, правила
/tests/pricing.test.js  тести розрахунку (Node, без залежностей)
/assets/            зображення (оптимізовані, з alt)
```

## Якість
- Mobile-first, мінімальна ширина 360 px, без горизонтального скролу.
- Семантична розмітка, `alt`, підписи до полів, видимий фокус, контраст ≥ 4.5:1, навігація з клавіатури.
- Цінова логіка тільки в `pricing.js`; дати в ISO (`YYYY-MM-DD`), працювати з UTC, щоб не ловити зсув часових поясів.
- Після змін запускай `node tests/pricing.test.js` і перевіряй сторінку локально (`npx serve .` або `python3 -m http.server`).

## Git
- Невеликі коміти зі зрозумілими повідомленнями (українською або англійською, послідовно).
- Не коміть `.env`, секрети, великі файли.
- Гілка `main`, розгортання з неї.

## Заборонено
- Додавати залежності чи CDN без запиту.
- Переписувати файли повністю, якщо достатньо точкової зміни.
- Видаляти файли без підтвердження.
